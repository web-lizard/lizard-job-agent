# Политика безопасности

## Поддерживаемая версия

Исправления безопасности готовятся для последней версии ветки `main`.

## Сообщение об уязвимости

Не создавайте публичный issue, если проблема может раскрыть API-ключи, персональные данные или позволить незаметно отправить форму.

Используйте приватное сообщение владельцу репозитория через функцию **Private vulnerability reporting** на вкладке **Security** в GitHub. Укажите затронутую версию, минимальные шаги воспроизведения, возможное влияние и предложенный способ исправления. Не прикладывайте реальные ключи или резюме.

Если приватные отчёты в репозитории недоступны, свяжитесь с владельцем профиля `web-lizard` через доступный в GitHub закрытый канал и передайте только краткое описание до согласования безопасного способа обмена деталями.
