# Участие в разработке

Спасибо за интерес к Lizard Job Agent. Проект принимает небольшие, проверяемые изменения с понятным описанием пользовательского эффекта.

## Перед началом

1. Проверьте существующие issues, чтобы не дублировать работу.
2. Для крупного изменения сначала создайте обсуждение или issue.
3. Создайте отдельную ветку от актуальной `main`.
4. Не используйте реальные персональные данные в тестах и примерах.

## Требования к изменению

- интерфейс и пользовательская документация пишутся по-русски;
- идентификаторы в коде остаются понятными английскими именами;
- новая логика сопровождается тестом;
- отправка форм всегда остаётся ручной;
- номерные копии файлов вида `content-i11.js` не создаются;
- версия меняется только в рамках отдельной задачи выпуска.

Перед pull request выполните:

```powershell
npm ci
npm run check
npm run build
```

В pull request опишите проблему, решение, способ проверки и влияние на приватность. Для изменений интерфейса приложите снимок экрана без персональных данных.
