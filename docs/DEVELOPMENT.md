# Разработка

## Требования

- Node.js 20 или новее;
- npm 10 или новее;
- Firefox 115 или новее;
- PowerShell, Bash или другая оболочка с поддержкой npm-скриптов.

## Подготовка окружения

```powershell
npm ci
Copy-Item resume.example.json resume.json
npm run check
```

Используйте вымышленные данные при разработке тестов и примеров. Не добавляйте API-ключи, реальные контакты и содержимое личного резюме в исходники, снимки экрана или логи.

## Локальный запуск

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Выберите **«Загрузить временное дополнение»**.
3. Укажите корневой `manifest.json`.
4. После изменения background- или content-скрипта перезагрузите дополнение.
5. Обновите вкладку HH.ru или Google Forms, чтобы content-скрипт подключился заново.

## Проверки

Полная локальная проверка:

```powershell
npm run check
```

Она последовательно выполняет строгую проверку TypeScript, тесты Vitest и синтаксическую проверку активных JavaScript-файлов.

Для одного тестового файла:

```powershell
npx vitest run tests/field-matcher.test.ts
```

Для ручной проверки распознавания обычной HTML-формы можно открыть `tests/fixtures/manual-form.html`.

## Сборка и архив

```powershell
npm run build
npm run package
```

`build` каждый раз заново создаёт `dist/`. `package` помещает ZIP в `web-ext-artifacts/`. Оба каталога исключены из Git.

В `dist/resume.json` копируется только `resume.example.json`. Это сделано намеренно: сборочный процесс не должен незаметно упаковать персональные данные разработчика.

## Добавление поддержки поля

1. Добавьте распознавание метки и типа поля в соответствующий модуль `src/content/` или активный `content.js`.
2. Не перезаписывайте непустое значение без явного разрешения.
3. Генерируйте события, которых ожидает React/Vue-форма сайта.
4. Добавьте минимальный DOM-пример и тест в `tests/`.
5. Проверьте, что форма не отправляется автоматически.

## Диагностика

При ошибке используйте кнопку копирования диагностики в панели. В отчёт не должны попадать API-ключ, телефон, email, резюме и полный текст сообщений. Если добавляется новое поле диагностики, отдельно проверьте его на утечку персональных данных.
