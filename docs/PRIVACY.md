# Приватность и безопасность данных

Lizard Job Agent обрабатывает резюме, сообщения работодателей и содержимое форм. Это чувствительные данные, поэтому проект следует запускать только из доверенной сборки и с собственным API-ключом.

## Что хранится локально

- `resume.json` находится рядом с локальной копией расширения и исключён из Git;
- API-ключ и настройки сохраняются в `browser.storage.local` профиля Firefox;
- текст вакансии для Google Forms может временно сохраняться в локальном хранилище расширения.

## Что передаётся DeepSeek

Модели передаются вопросы, относящийся к вакансии контекст и обезличенная часть резюме, необходимая для подготовки ответа. Телефон и email удаляются перед запросом. API-ключ передаётся только на настроенный URL DeepSeek.

Не используйте сторонний URL API, если не доверяете его владельцу: такой сервер получит ключ и содержимое запроса.

## Что расширение не делает

- не отправляет отклики, сообщения и формы автоматически;
- не обходит CAPTCHA, лимиты и антиспам-механизмы;
- не включает локальный `resume.json` в ZIP при стандартной сборке;
- не добавляет API-ключ и персональные данные в диагностику;
- не публикует данные в GitHub.

## Рекомендации

- создайте отдельный API-ключ с минимально необходимыми лимитами;
- проверяйте URL API перед сохранением;
- вручную просматривайте каждый сгенерированный текст;
- удалите данные расширения из Firefox после завершения работы на чужом компьютере;
- перед публикацией архива проверьте его содержимое командой `npm run package` и просмотром ZIP.

О найденной уязвимости сообщайте по правилам из [SECURITY.md](../SECURITY.md).
