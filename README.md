# 🦎 Lizard Job Agent

Firefox-расширение для подготовки осознанных откликов на вакансии HH.ru. Оно заполняет подтверждённые данные из локального резюме, обращается к DeepSeek только для открытых вопросов и всегда оставляет отправку за пользователем.

Текущая версия: **0.10.0** · сборка `I10-20260803` · статус: активная разработка.

## Что умеет расширение

- находит формы отклика, вопросы работодателя и чат на HH.ru;
- распознаёт поля в обычном DOM, iframe и открытом Shadow DOM;
- подставляет факты из `resume.json`, не перезаписывая уже введённый текст;
- готовит черновики ответов и сопроводительных писем через DeepSeek;
- заполняет текстовые поля Google Forms по описанию вакансии;
- открывает поиск вакансий по сохранённому запросу и региону;
- формирует обезличенную диагностику без API-ключа, телефона, email и резюме;
- не нажимает кнопки отправки и не обходит антиспам-механизмы.

## Быстрый старт

Понадобятся Node.js 20 или новее, npm и Firefox 115 или новее.

```powershell
git clone https://github.com/web-lizard/lizard-job-agent.git
cd lizard-job-agent
npm ci
Copy-Item resume.example.json resume.json
npm run check
```

Заполните локальный `resume.json` своими данными. Этот файл исключён из Git и не должен попадать в коммиты.

Затем откройте в Firefox `about:debugging#/runtime/this-firefox`, нажмите **«Загрузить временное дополнение»** и выберите корневой `manifest.json`. После изменения кода нажмите **«Перезагрузить»** на странице отладки и обновите целевую вкладку.

## Настройка

1. Нажмите значок расширения — откроется отдельная постоянная панель.
2. Перейдите в **«Настройки»**.
3. Укажите API-ключ DeepSeek, модель и URL API.
4. При необходимости настройте вступление, подпись, поисковый запрос и регион HH.ru.
5. Откройте вакансию или форму и подготовьте черновик нужной кнопкой в панели.
6. Обязательно проверьте результат и отправьте его вручную.

API-ключ хранится в `browser.storage.local`. Для запроса к модели персональные контакты удаляются из резюме. Подробнее: [приватность и безопасность](docs/PRIVACY.md).

## Команды проекта

| Команда | Назначение |
| --- | --- |
| `npm run check` | Проверить типы, запустить тесты и проверить синтаксис активных скриптов |
| `npm test` | Запустить все автоматические тесты один раз |
| `npm run test:watch` | Запустить тесты в режиме наблюдения |
| `npm run build` | Проверить проект и собрать чистый каталог `dist/` |
| `npm run package` | Собрать ZIP в `web-ext-artifacts/` |

Сборка намеренно кладёт в `dist/resume.json` только обезличенный пример. Персональный локальный файл никогда не включается в архив автоматически.

## Структура

```text
├── manifest.json          # активный манифест Firefox
├── background.js          # фоновые задачи, настройки и запросы к DeepSeek
├── content.js             # поиск и безопасное заполнение полей на странице
├── popup.*                # постоянная панель управления
├── options.*              # страница настроек
├── src/                   # типизированные модули и компоненты приложения
├── tests/                 # модульные и интеграционные тесты
├── scripts/               # сборка и упаковка расширения
├── docs/                  # подробная документация
└── .github/               # CI и шаблоны для GitHub
```

Архитектура и границы модулей описаны в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), рабочий процесс разработчика — в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Ограничения

- интерфейс HH.ru меняется, поэтому селекторы периодически требуют обновления;
- закрытый Shadow DOM недоступен расширению;
- ответы модели являются черновиками и могут содержать ошибки;
- проект не предназначен для массовых автоматических откликов;
- ключ DeepSeek нужен только для генерации свободного текста, локальные поля заполняются без него.
