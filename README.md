# 🦎 Lizard Job Agent

> Firefox-помощник для осознанных откликов на HH.ru
> **Версия 0.6.0 · Итерация 06 · `I06-20260802`**

Lizard Job Agent читает открытый чат или форму отклика, использует локальный `resume.json` и DeepSeek, а затем вставляет подготовленный текст как черновик. Отправка всегда остаётся за пользователем.

## Возможности

- читает активный чат HH.ru, включая modal, iframe и open shadow DOM;
- определяет последнее входящее сообщение и исключает быстрые ответы;
- готовит честный ответ по фактам из `resume.json`;
- создаёт уникальную середину сопроводительного письма под конкретную вакансию;
- добавляет отключаемое фирменное вступление;
- добавляет отключаемую подпись о Lizard Job Agent со ссылкой на GitHub;
- открывает поиск HH.ru по сохранённому запросу и региону;
- сохраняет существующий пользовательский текст;
- копирует безопасную диагностику без API-ключа, телефона, email и резюме.

## Установка

1. Скопируйте `resume.example.json` в `resume.json` и заполните своими данными. `resume.json` исключён из Git.
2. Откройте `about:debugging#/runtime/this-firefox` в Firefox.
3. Нажмите **«Загрузить временное дополнение»**.
4. Выберите корневой `manifest.json`.
5. После обновления кода нажмите **«Перезагрузить»** и обновите вкладку HH.ru.

В popup должны отображаться `ИТЕРАЦИЯ 06` и `I06-20260802`. Если номер другой, Firefox использует старую копию.

## Настройка

Откройте **Настройки** из popup:

1. сохраните DeepSeek API Key, модель и API URL;
2. настройте фирменное вступление;
3. включите или выключите честную подпись;
4. проверьте ссылку `https://github.com/web-lizard/lizard-job-agent`;
5. задайте поисковый запрос и код региона HH.ru;
6. при проблеме включите диагностику.

Поддерживается маркер `{url}` в подписи. Он заменяется ссылкой на проект.

## Ответ работодателю

1. Откройте конкретный чат на HH.ru.
2. Нажмите **«Подготовить ответ»**.
3. Проверьте вставленный черновик.
4. Отправьте сообщение вручную.

## Сопроводительное письмо

1. Откройте форму отклика с полем сопроводительного письма.
2. Нажмите **«Подготовить сопроводительное»**.
3. DeepSeek сформирует уникальную центральную часть по вакансии и резюме.
4. Расширение добавит включённые фирменные блоки и вставит письмо.
5. Проверьте текст и отправьте отклик вручную.

## Поиск вакансий

Кнопка **«Открыть поиск вакансий»** создаёт новую вкладку HH.ru с сохранённым запросом, регионом и сортировкой по дате публикации. Расширение не обходит антиспам, не выполняет массовые отклики и не отправляет формы по таймеру.

## Приватность и безопасность

- API-ключ хранится в `browser.storage.local`;
- ключ никогда не передаётся странице и не записывается в консоль;
- телефон и email удаляются из данных для DeepSeek;
- расширение не нажимает кнопки отправки и не вызывает `submit`;
- ответы и письма являются черновиками для ручной проверки.

## Активные файлы

Сборка не требуется. Корневой manifest подключает:

```text
popup-i06.html / popup-i06.js / popup-i06.css
content-i06.js
background-i06.js
options-i06.html / options-i06.js / options-i06.css
resume.json
```

Корневой каталог и `dist` синхронизированы. Старые `src`, backup и `popup-safe` не подключены активным manifest.

## Проверка разработки

```powershell
node --check background-i06.js
node --check content-i06.js
node --check popup-i06.js
node --check options-i06.js
npm.cmd test
```

При ошибке нажмите **«Скопировать диагностику»** в popup. Отчёт содержит версию, build ID, frame, тип страницы и статусы обнаружения без персональных секретов.
