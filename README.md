# Lizard Job Agent

Firefox WebExtension для безопасного заполнения открытой формы резюме на HH.ru данными из единого локального профиля.

Расширение **не отправляет форму**, не откликается на вакансии, не нажимает «Сохранить» или «Опубликовать» и не передаёт профиль на сервер. Перед сохранением пользователь проверяет заполненные поля сам.

## Что уже умеет

- хранит профиль в `browser.storage.local`;
- редактирует личные данные, цель, навыки, опыт, образование, языки и ссылки;
- автоматически сохраняет изменения;
- импортирует и экспортирует профиль в JSON;
- распознаёт поля по `label`, `placeholder`, `name`, `id`, ARIA и `data-qa`;
- заполняет обычные `input`, `textarea`, `select`, checkbox и часть React/Vue combobox;
- поддерживает несколько блоков опыта, если страница позволяет добавить их без отправки формы;
- не перезаписывает заполненные поля по умолчанию;
- показывает отчёт и на 10 секунд подсвечивает результат;
- не пишет телефон, email и полный текст резюме в консоль.

## Быстрый запуск

Требуется Node.js 20+.

```bash
npm install
npm run build
```

Готовое распакованное расширение будет в `dist/`.

Для разработки интерфейса:

```bash
npm run dev
```

Для тестов:

```bash
npm test
npm run typecheck
```

Для сборки ZIP:

```bash
npm run package
```

## Установка временного расширения в Firefox

1. Выполните `npm run build`.
2. Откройте в Firefox `about:debugging#/runtime/this-firefox`.
3. Нажмите **«Загрузить временное дополнение…»**.
4. Выберите `dist/manifest.json`.
5. После первой установки обновите уже открытую вкладку HH.ru, чтобы content script загрузился.

Временное дополнение исчезает после перезапуска Firefox. Для постоянной установки Firefox требует подписанный XPI.

## Как загрузить готовое резюме

Реальный профиль находится в корне рабочего проекта в файле `profile.local.json`. Файл добавлен в `.gitignore` и не попадёт в коммит.

1. Откройте настройки Lizard Job Agent.
2. В блоке **«Импорт и резервная копия»** нажмите **«Импортировать JSON»**.
3. Выберите `profile.local.json`.
4. Проверьте данные и вернитесь на открытую форму HH.ru.
5. Нажмите значок расширения → **«Заполнить страницу»**.

После импорта профиль хранится в локальном хранилище конкретного Firefox-профиля. Если удалить расширение или очистить его данные, профиль может быть потерян — периодически делайте экспорт JSON.

## Куда класть API-ключ

Для текущего MVP API-ключ **не нужен**: ТЗ прямо исключает внешний AI API, а распознавание работает локальными правилами.

Если позже появится генерация текста через API, секрет нельзя класть:

- в `manifest.json`, исходники, `.env` с префиксом `VITE_` или собранный `dist`;
- в `browser.storage.local` как «секрет» — пользовательское расширение и его код могут его прочитать;
- в GitHub, issue, чат или JSON-профиль.

Безопасная схема для будущей AI-функции: небольшой backend/proxy хранит ключ в переменной окружения `OPENAI_API_KEY`, а расширение обращается к backend по пользовательской авторизации и с ограничениями. Для локального прототипа ключ можно задавать только процессу локального backend через системную переменную окружения или `.env`, исключённый из Git; в код расширения он всё равно не должен попадать.

## Безопасность

- Доступ к страницам ограничен доменом `hh.ru`.
- Заполнение запускается только вручную из popup.
- Опция «Не перезаписывать заполненные поля» включена по умолчанию.
- Код от внешнего AI не исполняется.
- Кнопки с текстом «Сохранить», «Отправить», «Откликнуться» и «Опубликовать» исключены из сценария.

## Структура

```text
src/
├── adapters/       # HH.ru и общий эвристический адаптер
├── background/     # background script Firefox
├── content/        # поиск, сопоставление и заполнение полей
├── options/        # редактор локального профиля
├── popup/          # запуск заполнения и отчёт
├── profile/        # типы, валидация и storage
├── shared/         # сообщения, логирование, нормализация
└── manifest.json
```

## Ограничения MVP

HH.ru периодически меняет DOM и `data-qa`. Эвристический адаптер не заполняет поле при низкой уверенности и выносит его в отчёт. Сложные подсказки города/отрасли могут потребовать ручного выбора. Расширение принципиально не сохраняет промежуточные модальные формы, поэтому при сценарии HH.ru, где новое место работы создаётся только кнопкой «Сохранить», добавьте блоки вручную и запускайте заполнение для каждого открытого блока.
